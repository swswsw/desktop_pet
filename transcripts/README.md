# 📜 Antigravity Conversation Transcripts

This directory contains the exported raw session transcripts for this project.

## System Storage Location
Antigravity automatically records and stores all session logs on your local machine at:

```
/config/.gemini/antigravity/brain/<conversation-id>/.system_generated/logs/
```
